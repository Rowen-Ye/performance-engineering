# 领域分析路径
这里的覆盖指分析入口，不代表已在所有硬件上验证。

| 领域 | 首先区分 | 模型/证据 | 实验方向 |
|---|---|---|---|
| CPU | 计算、前端、后端、错误预测、调度 | Top-down、IPC、cycles、火焰图、on/off CPU | 固定亲和性与频率，改关键路径 |
| GPU/NPU | 算子、搬运、调度、通信、设备空闲 | Roofline、设备时间线、实际 FLOPs/字节 | 隔离算子与端到端，显式同步 |
| LLM 推理 | Prefill/Decode、排队/执行、TP/EP、KV | TTFT、TPOT、tokens/s、HBM、路由偏斜 | 固定长度/到达率/精度，对比批处理或算子 |
| 内存/NUMA | 容量、带宽、延迟、cache miss、远端 | 带宽与数据量、numastat、拓扑 | 绑定/交错分配前先确认放置及权限 |
| 虚拟化/容器 | steal、调度、陷入、复制、限额 | host/guest 时间线、cgroup throttle、关键路径 | 匹配宿主/客体负载，隔离限额影响 |
| 网络/RDMA | 带宽、RTT、丢包、拥塞、消息率 | BDP、链路计数、完成队列、端到端 trace | 多消息大小/队列深度，确认 MTU/路径 |
| 分布式系统 | 串行段、协调、偏斜、通信、尾延迟 | Amdahl、关键路径、Little、分布式 trace | 扩展曲线、热点与节点故障影响 |
| 存储/I/O | 吞吐、IOPS、延迟、队列、cache | 请求大小、读写比、队列深度、设备统计 | 区分缓存/持久化语义；fio 不得写业务盘 |

厂商计数器语义、设备峰值与框架实现随版本变化，应查当前版本一手资料。
